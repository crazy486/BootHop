# Quick Hop minimal implementation plan

1. Add a platform-neutral, fakeable startup coordinator in the GUI crate. It loads the untrusted display cache, sends exactly one fixed-OS `Switch` only when the cache is a usable matching hint, validates the returned report with the existing controller contract, and returns `Success`, `ShowSetup`, or `ShowError` without retry.
2. Test unconfigured/unreadable/wrong-OS cache, accepted Switch, failed/unknown Switch, and repeated invocation. Prove that only the configured path sends one request and that tests use fake helpers only.
3. Wire Linux and Windows entry points so Quick Hop completes before constructing `AppWindow`. Accepted success exits with no Slint window; setup flags, missing configuration, and failures reuse the existing window. Preserve bounded raw diagnostics.
4. Update only static/UI tests invalidated by the new startup contract. Run fmt, targeted tests, workspace tests, Clippy, packaging/capability checks, and CI.
5. Defer passwordless polkit and Windows no-UAC architecture. Do not perform real helper, firmware, Switch, or reboot acceptance in this plan.
